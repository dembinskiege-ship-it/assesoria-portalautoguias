SITE — JULIA GRACIELLY ALVES FERREIRA

Arquivos:
- index.html: página inicial / apresentação.
- sobre.html: página institucional.
- politica-privacidade.html: política de privacidade.
- termos-de-uso.html: termos de uso.
- assets/style.css: estilos personalizados.
- assets/*.jpg: imagens enviadas e utilizadas no site.

Como visualizar:
1. Extraia o arquivo ZIP.
2. Abra index.html no navegador.
3. Para publicar, envie a pasta inteira mantendo a estrutura de arquivos para sua hospedagem.

Tecnologias:
- HTML5
- CSS3 personalizado
- Bootstrap 5.3.3 via CDN
- Bootstrap Icons via CDN
- Google Fonts via CDN

Observações importantes:
- O site depende de internet para carregar Bootstrap, ícones e fontes externas.
- Confirme se os serviços descritos nas imagens e textos correspondem exatamente aos serviços oferecidos.
- Revise os documentos legais de acordo com as ferramentas reais do site (cookies, analytics, Google Ads, formulários, pixels etc.). A política atual é um modelo inicial e não configura consentimento de cookies nem garante conformidade jurídica por si só.
- Antes de anunciar no Google Ads, informe dados e serviços verdadeiros, revise as políticas de publicidade aplicáveis e configure corretamente tags e consentimento quando necessários.
